# privacy

Public privacy policies for We Enable Climbers' internal Chrome extensions, served by GitHub Pages
at https://we-enable-climbers.github.io/privacy/. The Chrome Web Store listings link here; the
extension repos themselves are private (GitHub Free can't serve Pages from a private repo).

| Page | URL | Source of truth |
|---|---|---|
| TMS Tweaks | https://we-enable-climbers.github.io/privacy/tms-tweaks/ | `docs/privacy.html` in We-Enable-Climbers/tms-tweaks |
| Freshdesk Tweaks | https://we-enable-climbers.github.io/privacy/freshdesk-tweaks/ | `store/PRIVACY.md` in We-Enable-Climbers/freshdesk-tweaks |

When an extension starts handling data differently, update the source in its own repo and copy the
change here in the same go. Pages publishes from `main` (root); there is no build step.
